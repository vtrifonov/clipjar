**Behaviour (R81 read phase):** start `snapshot(changeCount, types, declaredSource: pb.declaredSource())`.
1. If `fileURL ∈ types`: `urls = pb.fileURLs()`; non-empty → set and return `.snapshot` (nothing else read);
   empty → fall through (A26).
2. If `string ∈ types`: `s = pb.string()`; if `s` has a non-whitespace character: `s.utf8.count >
   maxTextBytes` → `.oversized`; else set `string`, then read `rtf` (if in types) and `html` (if in types),
   each kept only if `count ≤ FilterSettings.maxRichBytes`; return `.snapshot`.
3. If `png ∈ types`: read png only (TIFF **never** read when PNG is declared); `count > maxImageBytes` →
   `.oversized`; else `image = ImageData(data, png)`; `.snapshot`. Else if `tiff ∈ types`: same for tiff.
4. Otherwise `.empty` (also when a declared rep returns nil).

- `textWithRichReps` — rtf & html kept.
- `oversizedRtfDroppedAlone` — rtf `Data(count: 2_000_001)` → `rtf == nil`, `html` kept, `string` kept.
- `stringPlusHugeTiffNeverReadsTiff` — types `{string, tiff}`, tiff `Data(count: 60_000_000)` →

- `pngPreferredTiffNeverRead` — `{png, tiff}` → image uti `public.png`; `reads["public.tiff"] == nil`.
- `giantPngAloneIsOversized` — `Data(count: 20_000_001)` → `.oversized`.
- `textOverOneMegabyteIsOversized` — 1,000,001 × `"a"` → `.oversized`; exactly 1,000,000 → `.snapshot`.
- `whitespaceStringFallsThroughToImage` — `" \n "` + png → image snapshot.
- `filesWinAndNothingElseRead` — `{fileURL, string, png}` → `fileURLs` set; `reads["public.utf8-plain-text"] == nil`, `reads["public.png"] == nil`.
- `declaredFileURLButEmptyFallsBackToString` (A26) → `string` set.
- `nothingUsableIsEmpty` — `{"com.example.custom"}` → `.empty`.

```swift
@MainActor public final class ClipboardWatcher {
    public init(pasteboard: PasteboardReading,
                settings: @escaping @MainActor () -> FilterSettings,
                frontmostApp: @escaping @MainActor () -> SourceApp?,
                runningAppName: @escaping @MainActor (String) -> String? = { _ in nil },  // name of a running app with that bundle id
                ownBundleID: String,
                clock: @escaping @MainActor () -> Date = Date.init,
                sink: @escaping @MainActor (CapturedContent, SourceApp?, Date) -> Void)
    public func start(interval: Duration = .milliseconds(300))
    public func stop()
    public func poll()
    public func appActivated(_ app: SourceApp)
    public var onCapture: (@MainActor () -> Void)?
    public static func attributedSource(declared: SourceApp?, frontmost: SourceApp?, ownBundleID: String) -> SourceApp?
}
```

**Behaviour:**
- State: `lastChangeCount: Int? = nil` (so the first poll captures the clipboard present at launch),
  `frontmostAtLastTick: SourceApp?`, `activatedSinceTick: [SourceApp]`.
- `poll()` exactly in this order:
  1. `frontNow = frontmostApp()`; `prevFront = frontmostAtLastTick`; `activated = activatedSinceTick`;
     then **always** `frontmostAtLastTick = frontNow; activatedSinceTick = []` (N4 — also on no-change ticks).
  2. `cc = pasteboard.changeCount`; if `cc == lastChangeCount` return; set `lastChangeCount = cc` **before**
     any filtering (content copied while paused/ignored is never captured later).
  3. `types = pasteboard.types()`; `declared = pasteboard.declaredSource()`;
     `declaredApp = declared.map { SourceApp(bundleID: $0, name: runningAppName($0)) }`.
  4. candidates = `[declaredApp, prevFront] + activated + [frontNow]` (compactMap). `ClipFilter.preflight`;
     reject → `Log.capture.info` with the reason only; return. (Zero content reads so far.)
  5. `ClipReader.read`; `.oversized`/`.empty` → log reason; return. `ClipExtractor.extract`; nil → return.
  6. `source = attributedSource(declared: runningAppName(declared) != nil ? declaredApp : nil, frontmost: frontNow, …)`;
     `sink(content, source, clock())`; `onCapture?()`.
- `attributedSource`: `declared ?? frontmost`; if the result's `bundleID == ownBundleID` → `nil`.
  (Reconciliation: preflight already rejects copies while Clipjar is a candidate, so "Clipjar frontmost"
  is asserted twice: the watcher does not capture, and `attributedSource` returns nil.)
- `start`: `task = Task { [weak self] in while !Task.isCancelled { self?.poll(); try? await
  Task.sleep(for: interval, tolerance: .milliseconds(100)) } }` (polls immediately); `stop` cancels.
  No `Timer`.

`sinkCalls: [(CapturedContent, SourceApp?, Date)]`):

- `noChangeNoSink` — second `poll()` → still 1.

- `pausedContentNotCapturedAfterResume` — copy while paused, poll, resume, poll → 0 sinks.
- `declaredSourcePreferredWhenRunning` — declared `com.example.editor`, `runningAppName` → `"Editor"`,

- `declaredSourceNotRunningFallsBackToFrontmost` → source TextEdit.
- `clipjarFrontmostIsNotCaptured` — frontmost `AppIdentity.bundleID` → 0 sinks; and

- `ignoredActivatedWithinTickRejected` (R82) — poll (frontmost Safari); `appActivated(1Password)`;
