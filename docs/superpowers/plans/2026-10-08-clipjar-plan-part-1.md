are never hashed. R67: logs never contain clip content, previews, clip file paths or hashes.

- `.kindIsPartOfHash` — `of(.text,"https://example.com") != of(.link,"https://example.com")`.
- `.richDataNotHashed` — two `CapturedContent` differing only in `rtf`/`html` → equal `of(_:)`.
- `.fileOrderMatters` — `[a,b]` vs `[b,a]` → different.
- `.imageHashUsesBytes` — same bytes equal; one byte changed → different.
- `SearchFoldingTests.foldsCaseAndDiacritics` — `fold("Café") == fold("cafe")`, `fold("Äpfel").hasPrefix("a")`,
  `fold("ÄPFEL") == fold("äpfel")`.

**Requirements:** R16 (text preview), R18, R20, R21. Review Focus #1 (grapheme safety).

public enum TextHeuristics {
    public static let previewLimit = 300
    public static func previewText(_ s: String) -> String
    public static func isLink(_ s: String) -> Bool
    public static func linkDomain(_ s: String) -> String?        // host minus leading "www."; nil if not a link

**Behaviour:**
- `previewText`: every run of Unicode whitespace/newlines (`Character.isWhitespace`, which includes
  newlines) → one space; trimmed; truncated to 300 **Characters** (grapheme-safe). Stop scanning once
  300 output characters exist (1 MB inputs must be cheap).
- `isLink` (R18): trimmed text has no whitespace, length ≤ 2,048, and either `URL(string:)` has scheme
  `http`/`https` and a non-empty host, or it starts with `www.` and `URL(string: "https://" + text)` has a
  host containing a dot.
- `hexColor` (R20): trimmed matches `^#?([0-9a-fA-F]{3}|[0-9a-fA-F]{6}|[0-9a-fA-F]{8})$`; 3-digit expands
  each nibble (`F80` → `FF8800`); 8-digit is RRGGBBAA; otherwise alpha 1.
- `isCodeLike` (R21): contains any of `{`, `};`, `=>`, `</`, `#include`, `func `, `def `; or ≥ 2 lines of
  which ≥ 1 starts with a tab or 4 spaces.

**Tests first** (`@Test(arguments:)` tables where listed):
- `previewCollapsesWhitespace` — `"  Hello,\n\n\tClipjar  "` → `"Hello, Clipjar"`.
- `previewCutsAt300Characters` — 1,000 × `"a"` → `count == 300`.
- `previewIsGraphemeSafe` — 299 × `"a"` + `"👩‍👩‍👧"` + `"bbb"` → `count == 300` and `hasSuffix("👩‍👩‍👧")`.
- `previewOfOneMegabyteIsFast` — 1,000,000 × `"x"` → result count 300 (no timing assert; must not hang).
- `isLink` table: true for `https://example.com/docs`, `http://example.com`, `www.example.com`,
  `"  https://example.com  "`; false for `foo bar.com`, `mailto:hello@example.com`, `https://`,
  `ftp://example.com`, `example.com`, `"https://example.com/" + 2,048 × "a"`.
- `linkDomainStripsWWW` — `"https://www.example.com/a"` → `"example.com"`; `"www.example.com"` → `"example.com"`.
- `hexColor` table: `#FF8800` → (1, 0.5333…, 0, 1) within 0.001; `F80` == `#FF8800`; `#FF880080` → a ≈ 0.502;
  invalid: `#FF88`, `#GG8800`, `FF 8800`, `""` → nil.
- `isCodeLike` table: true for `func greet() {`, `a => b`, `</div>`, `#include <stdio.h>`, `def run():`,
  `"x\n    y"`, `"x\n\ty"`; false for `Hello, world`, `"    single"`.

**Steps:** tests → `swift test --filter TextHeuristicsTests` FAIL → implement → PASS → commit

**Behaviour (R36):** WHERE clauses ANDed; all terms folded with `SearchFolding.fold` and empty terms

- `SELECT id, kind, previewText, sourceBundleID, sourceAppName, lastCopiedAt, isPinned, thumbnailPath,
  imageWidth, imageHeight, byteSize, json_array_length(fileURLs) AS fileCount FROM clip … ORDER BY
  lastCopiedAt DESC, id DESC LIMIT ?`. Pinned rows are **not** floated. All values bound as arguments.

**Tests first** — `@Test(arguments: Backend.allCases)`, rows seeded with `Clip.make` (migrate first):

- `shortTermUsesEscapedLike` — rows "xaby", "100% done", "a_b", "axb": `["ab"]` → [xaby]; `["%"]` → [100% done];
